Accept crypto payments in your business

CryptoPay works like Stripe, but for Ethereum. Your backend creates a payment with one API call, the customer pays from MetaMask, and your server gets a signed webhook when the money arrives. Funds go straight to your own wallet.

Open merchant dashboard Explore the API

How it works

  1. Register your business and get a secret API key.
  2. Your server calls POST /v1/payments and gets a checkout_url.
  3. The customer opens the link and pays with MetaMask (Sepolia testnet).
  4. CryptoPay verifies the transaction on the blockchain and sends you a webhook.

One API call

curl -X POST $BASE/v1/payments \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -d '{"amount": "0.001",
       "order_id": "ORDER-1024",
       "description": "Latte x2"}'

Response contains id, status: "pending" and checkout_url.
